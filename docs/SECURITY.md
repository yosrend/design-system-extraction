# Security Policy

## Reporting

Do not disclose vulnerabilities, leaked credentials, personal data, or private source material in a public issue. Use GitHub's private vulnerability reporting feature when it is available for this repository.

## Scope

Reports are relevant when the skill could cause an agent to expose secrets, cross an authorization boundary, execute untrusted page instructions, bypass access controls, or republish protected/private material.

The skill treats third-party page content as untrusted data and requires explicit authorization for private or authenticated sources.
